The first public beta of LiquidMouse, a liquid cursor for the Mac. For macOS 15 and later, on Apple silicon and Intel.

Pick a dot or an arrow: it stretches into a tail as you move, splashes when you click and takes the matching shape over text, links, window edges and anything you can drag. Custom cursors it does not recognize stay native, and games keep their own cursor.

## Install

1. Download `LiquidMouse-v0.9.0-beta.1.zip` below and open it.
2. Drag **LiquidMouse** into **Applications** and open it.
3. This build is not notarized by Apple, so macOS blocks the first launch. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway** and confirm. There is no need to turn Gatekeeper off.
4. Click the drop in the menu bar for the settings. Optionally, grant Accessibility under **Buttons** to make the cursor precise over buttons too.

To check the download, put `SHA256SUMS` next to the zip and run `shasum -a 256 -c SHA256SUMS`.

## Known limits

- Tested mostly on macOS 27, and on Apple silicon Macs only. The app is also built for Intel, but it has not been run on an Intel Mac yet.
- Undocumented macOS calls are needed to hide the system cursor, so a macOS update can break it until LiquidMouse is updated.
- Button detection depends on what each app exposes to Accessibility.
- There is no automatic updater: use **Watch → Custom → Releases** on the repository to hear about new versions.

More in the [README](https://github.com/BeniaminoNardone/LiquidMouse#known-limits).
